# Typing Speed Test Desktop App

A desktop application built with Python and Tkinter that tests and measures a user's typing speed and accuracy in real-time.

## Features

- **Interactive GUI:** Designed cleanly with Tkinter widgets, featuring a clear text display area and an active typing input box.
- **60-Second Countdown Timer:** Automatically tracks test duration using asynchronous background event scheduling (`root.after`).
- **Performance Metrics:** Automatically calculates Words Per Minute (WPM) and cross-checks accuracy against the original sample text.
- **Reset Functionality:** Allows users to easily clear input fields and retake the test.

## Tech Stack

- **Python** (Core Logic & Calculations)
- **Tkinter** (Graphical User Interface)

How to Use
Launch the app and click ▶ Start Test.
The timer will start counting down from 60 seconds, and the input box will become active.
Type the sample text as quickly and accurately as you can before the time runs out.
View your final WPM and accuracy percentage instantly upon completion!
